# ESP32-S3-DevKitC KiCad library

This directory vendors only the ESP32-S3-DevKitC symbol and footprint from
Espressif's official KiCad library:

- Repository: https://github.com/espressif/kicad-libraries
- Source revision: `dd76561812ab300351234ba6e0ec1295641796f0`
- Mechanical drawing checked: ESP32-S3-DevKitC-1 Rev 1.1, 2022-04-29
  https://dl.espressif.com/dl/schematics/esp_idf/DXF_ESP32-S3-DevKitC-1_V1.1_20220429.pdf
- License: `LICENSE.Espressif.md` (CC BY-SA 4.0 with the stated exception)

The project library tables register both assets under the `PCM_Espressif`
nickname. Use `PCM_Espressif:ESP32-S3-DevKitC` for both the symbol and the
footprint.
