# USB 센서 캐리어

기존 ESP32-S3 개발보드를 두 열의 소켓에 꽂아 사용하는 회로다. 개발보드의 native USB가 전원과 micro-ROS serial 통신을 담당한다. [회로도 PDF](sensor_controller.pdf)와 [제조사 품번이 포함된 BOM](sensor_controller_bom.csv)을 함께 제공한다.

## 연결

J3–J6는 모두 Amphenol RJE01J4001, RJ11형 6P4C 커넥터다. 전원과 신호는 3.3 V이며, 두 신호선은 GPIO에 직결된다.

| 포트 | SCL / TRIG GPIO | SDA / ECHO GPIO | I2C 사용 |
| --- | --- | --- | --- |
| J3 | 42 | 41 | 하드웨어 I2C |
| J4 | 21 | 4 | 하드웨어 I2C |
| J5 | 5 | 6 | 소프트웨어 I2C 구현 필요 |
| J6 | 7 | 15 | 소프트웨어 I2C 구현 필요 |

| J3–J6 심벌 접점 | I2C 센서 | 초음파 센서 |
| --- | --- | --- |
| 1 | 3V3 | 3V3 |
| 2 | SCL | TRIG |
| 3 | SDA | ECHO |
| 4 | GND | GND |

J5/J6는 ToF 또는 TRIG/ECHO 초음파용으로 사용할 수 있다. J3/J4도 GPIO 모드를 선택하면 같은 배선 규칙으로 초음파를 연결할 수 있다. 한 포트에는 한 센서만 연결한다.

**접점 배치는 기존 센서 보드와 케이블 대조 전의 임시 할당이다.** 표의 번호는 회로도 심벌 번호다. 실제 잭 접점 번호와 케이블의 직결 또는 반전 여부를 대조해 확정한다. J3–J6의 PCB footprint는 해당 제조사 도면으로 정의할 수 있도록 미지정 상태로 두었다.

J1은 개발보드 왼쪽 열, J2는 오른쪽 열이다. 개발보드를 위에서 보고 안테나 쪽 접점이 각 열의 1번이다. 소켓의 열 간격은 22.86 mm, 접점 피치는 2.54 mm다. GPIO19/20은 native USB용으로 비워 둔다.

## 전기 조건

### I2C

네 포트의 SDA와 SCL 각각을 2.2 kΩ으로 3.3 V에 풀업한다. 약 1.5 m 케이블의 초기 시험 설정은 100 kHz다.

| 버스 | SDA 풀업 | SCL 풀업 | 부품 |
| --- | --- | --- | --- |
| I2C1, J3 | R7 | R8 | 0603WAF2201T5E, 2.2 kΩ, 1%, 0603, LCSC C4190 |
| I2C2, J4 | R9 | R10 | 동일 |
| 소프트웨어 I2C, J5 | R11 | R12 | 동일 |
| 소프트웨어 I2C, J6 | R13 | R14 | 동일 |

[VL53L7CH 데이터시트](https://www.st.com/resource/en/datasheet/vl53l7ch.pdf)의 Table 8은 상승시간 한계를 300 ns로 제시한다. 100 kHz 설정만으로 이 조건이 완화되는 것은 아니다. `tr ≈ 0.8473 × R × C`에서 명목 저항 2.2 kΩ일 때 300 ns에 해당하는 총 용량은 약 161 pF다. 총 용량 400 pF와 저항 오차 +1%를 가정하면 약 0.75 µs로 센서의 한계를 넘는다. 케이블 길이만으로 총 용량을 확정하지 않으며, 실제 센서 보드를 연결한 상태에서 각 버스의 상승시간과 LOW 전압을 측정한다.

기존 센서 보드의 풀업은 새 저항과 병렬로 연결된다. 예를 들어 기존 2.2 kΩ 풀업과 병렬이면 유효 저항은 1.1 kΩ이다. 센서 보드의 풀업값과 실제 LOW 전압을 확인하고, 중복 풀업이 과도하면 해당 버스의 캐리어 풀업 두 개를 미실장한다.

### 초음파와 전원

TRIG와 ECHO 모두 GPIO 직결이며 분압 저항과 모드 선택 점퍼는 없다. **3.3 V 전원과 3.3 V 신호를 지원하는 초음파 모듈만 연결한다.** 일반 HC-SR04의 5 V 전원 사양은 충족하지 않는다. 3.3 V TRIG 인식 여부와 3.3 V 전원 동작 여부는 별개다. ESP32-S3 GPIO에 5 V ECHO를 입력하지 않는다.

초음파 모드에서도 두 신호선의 2.2 kΩ 풀업은 연결되어 있다. LOW 출력 시 각 약 1.5 mA의 부하가 걸리므로 센서 출력의 LOW 전압을 확인한다. 초음파 전용 포트로 사용할 때는 해당 풀업 두 개를 미실장할 수 있다.

센서 전원은 개발보드의 3.3 V 출력에서 공급한다. 사용할 센서의 합산 최대 전류와 MCU 부하를 포함해 실제 개발보드 레귤레이터와 USB 전원 용량을 확인한다.

### 배터리 측정

J7의 1번은 배터리 팩 양극, 2번은 GND다. 상단 100 kΩ, 하단 22 kΩ, 100 nF 필터를 통해 GPIO1, ADC1_CH0에 연결된다. 입력 범위는 USB 전원이 켜진 상태에서 0–16 V다. 14.6 V 입력은 약 2.633 V이며 `Vbat = Vadc × 122 / 22`로 환산한다. ADC는 약 3.1 V를 수용하는 감쇠 설정과 보정을 사용한다. USB 전원 인가 후 J7을 연결하고, USB 전원 제거 전 J7을 분리한다. J7은 전압 측정 입력이며 보드 전원 입력이 아니다.

## JLCPCB 설정

PCB 파일은 외곽과 부품 배치가 없는 제작 설정 템플릿이다. 기본 제작 조건은 2층 FR-4, 1.6 mm, 외층 1 oz, 녹색 솔더마스크, 무연 HASL, 라우팅 외곽이다. 아래 값은 제조 한계가 아닌 보수적인 설계값이다.

| 항목 | 설정 |
| --- | --- |
| 최소 선폭 / 구리 간격 | 0.20 / 0.20 mm |
| 기본 신호 / 전원 선폭 | 0.25 / 0.50 mm |
| 비아 외경 / 드릴 | 0.80 / 0.30 mm |
| 최소 annular ring | 0.25 mm |
| 최소 홀 가장자리 간격 | 0.50 mm |
| 홀과 다른 구리의 최소 간격 | 0.30 mm |
| 구리와 라우팅 외곽 간격 | 0.30 mm |
| 솔더마스크 확장 | 면당 0.05 mm |
| 최소 솔더마스크 댐 | 0.10 mm |
| 최소 실크 높이 / 선 두께 / 간격 | 1.00 / 0.15 / 0.15 mm |

V-cut을 사용하면 구리와 외곽 간격을 0.50 mm 이상으로 조정한다. 솔더마스크 확장은 JLCPCB 안내 사이에 차이가 있으므로 주문 전 Gerber 미리보기와 DFM 결과를 확인한다.
