# 18F 공통8목표 컨트롤러 비교

목표별 각1회, 총24회. XY30cm/yaw10°이며 목적지 의자만 제거했다. Nav2 성공은 DWB5/8, MPPI7/8, TEB7/8. Nav2 성공과 GT30cm/10° 관측을 함께 만족한 것은 각각4/8,6/8,7/8이다.

TEB는 이번 시뮬레이션 시간에서7개 도착 목표 모두 MPPI보다 빨랐다. 그러나 호스트/실제RTF/제어주기가 달라 순수 알고리즘 효과로 단정할 수 없다. MPPI는 TEB보다7개 도착 목표 모두 선형/각 jerk RMS가 작았다. 실패로 정체한 구간의 낮은 jerk는 개선으로 해석하지 않는다.

DWB 실제 joint최대5.1285rad/s(3목표 초과), MPPI4.111rad/s, TEB4.99rad/s. DWB/MPPI seat43은 Nav2성공이나 GT32.90/33.31cm. 모든 controller의 다른 방 목표 실패에는 runtime planner/BT 문제가 관측되어 controller 단독 원인으로 단정할 수 없다.

연산 p95 범위: DWB8.12–13.23ms, MPPI10.91–26.88ms, TEB3.49–94.57ms. DWB 실패/예외의 짧은 연산도 포함되어 있으므로 단순 비용 순위화하지 않는다. TEB는 remote x86이며 절대 연산 순위 비교를 하지 않는다. 실제 RTF: DWB.220–.345, MPPI.217–.304, TEB.408–.426.

원자료 제약: DWB2개 rosbag후반 누락, TEB먼좌석 접촉 null과 원래 TEB알고리즘 파라미터 일괄조회8건 누락(별도 configure재검증). MPPI전체8bag 검증. 관측가능구간 환경접촉은 보고되지 않았지만 연속 무충돌 증명은 아니다. 접촉 episode정의도 다르므로 횟수 순위화하지 않는다.

현재 MPPI는 DWB를 대체할 검토 근거가 있고, TEB는 속도/실제도착오차 측면에서 검토할 가치가 있다. 부드러움에서는 MPPI가 더 유리하게 관측됐다. 각목표1회와 실행조건 차이 때문에 최종 교체 결론을 내리지는 않는다.
