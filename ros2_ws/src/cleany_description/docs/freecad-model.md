# FreeCAD 기준 모델

`Cleany-final.FCStd`의 저장된 조립 형상을 `freecad_final` 모델로 제공한다.
프레임, 양팔, PincOpen 집게, 손목 카메라, 헤드, 바퀴, 외장과 화면을 포함한다.
관절을 움직이는 모델이 아니라 CAD에 저장된 한 자세의 정적 기준 모델이다.
원본의 `DesignStatus`도 `layout-draft`다.
양쪽 손목 카메라에는 원본 형상 위에 사용자 실측 깊이를 반영한다. 내보내기
도구는 `freecad_wrist_camera_depth.json`이 있으면 PCB 위치와 광축을 기준으로
렌즈 몸체, 앞 유리와 마운트 뒤 면을 맞춘다. 렌즈 유리 앞 끝에서 PCB 뒤면은
9.5mm, 마운트 뒤 면은 26.7mm다. PCB, 손목 체결 위치와 광학 보정값은
유지하며 치수 출처는 형상 manifest에 기록한다.

## 모델 선택과 적용 범위

| 선택 | 용도 | 제약 |
|---|---|---|
| `freecad_final` | 정적 description 미리보기, 부품 배치와 표면 확인 | 관절 명령, 동역학, 파지와 센서 보정에 사용하지 않음 |
| `freecad_kinematic` | 추출한 축과 집게 핀 연동의 변화량 표시 | 영점·운용 제한·실물 접촉 미확정, 실제 제어용이 아님 |
| `legacy_runtime` | 기존 URDF의 관절, MoveIt, 제어와 기존 보정 비교 | 새 CAD 형상을 반영한 실행 모델이 아님 |

`description.launch.py`의 기본값은 `legacy_runtime`이다. CAD 미리보기는 명시적으로 선택한다. 기존 직접 진입점인
`cleany.urdf.xacro`, `cleany_control.urdf.xacro`와 `mjcf/cleany.xml`은 기존 실행
모델을 유지한다. 새 정적 모델은 기존 관절명과 TCP를 제공하지 않으므로 기존
MoveIt chain이나 컨트롤러 설정을 붙여 사용하지 않는다. 기존 실행기의 홈 자세,
충돌 구, 관절 보정과 접촉 판정도 새 CAD 기준으로 검증된 값이 아니다.

`namespace`는 robot description, joint state와 TF 토픽에 적용하고,
`frame_prefix`는 발행하는 TF frame ID에 적용한다. 둘의 기본값은 빈 문자열이다.
실물 관절 피드백을 사용하려면 현재 encoder 값과 CAD 기준 자세의 대응을
검증해야 한다. 실행 중인 주행 좌표와 CAD 전방 및 높이 원점도 먼저 맞춰야 한다.

회전축과 링크 소유 관계의 후속 추출은 [FreeCAD 운동학](freecad-kinematics.md)에
정리한다. 이 페이지의 null 값은 정적 기준 모델의 상태이며, 추출된 기하 축과
아직 미확정인 영점·구동 값은 운동학 manifest에서 구분한다.

새 URDF의 `cad_snapshot_*` 링크는 원본의 부품 그룹을 나타낸다. `fixed` 연결은
저장된 조립 자세를 표시하기 위한 것이며, 실제 팔이나 집게가 고정되어 있다는
뜻이 아니다. 모든 부품 메시를 `base_link` 좌표로 내보내 그룹 원점은 항등 변환을
사용한다. 실제 관절 원점과 축을 추정해 넣지 않는다.

## 좌표와 형상 계약

| 항목 | 반영 내용 |
|---|---|
| 원본과 출력 단위 | FreeCAD mm → 메시 m |
| 전방과 좌측 | LiDAR가 장착된 CAD -Y → ROS +X, CAD +X → ROS +Y |
| 높이 원점 | CAD 지면 Z=-95.5 mm를 기준으로 기존 `base_link`의 지면 위 380 mm 좌표 관례 유지 |
| 변환식 | `x=-CAD_y/1000`, `y=CAD_x/1000`, `z=CAD_z/1000-0.2845` |
| 좌우 팔 | 원본 `RightArm` → 로봇 오른팔, `LeftArm` → 로봇 왼팔; 정면에서 보이는 좌우와 구분 |
| 프레임 기둥 | 원본 560 mm 반영; 기존 실행 모델의 660 mm와 다름 |
| 메시 배치 | BREP에 포함된 객체 Placement를 한 번 사용하고 상위 App::Part Placement를 합성 |
| 형상 세분화 | 최대 선형 편차 설정 0.35 mm, 각도 0.35 rad; 각 면의 CAD 경계를 벗어난 결과나 작은 면은 더 세밀하게 재시도 |
| 색상과 화면 | 저장된 부품별 색상과 내장 `idle.png` 사용 |
| 충돌 | URDF에 동일한 삼각형 표면 제공; 움직이는 로봇의 충돌 근사나 SolidFCL용 볼록 분해로 인증한 형상은 아님 |
| MuJoCo | 월드에 고정된 시각 기준 모델. actuator와 joint 없이 접촉 비활성화 |

높이 변환은 좌표계를 맞추는 관례이며 실물 측정이나 새로운 보정 결과가 아니다.
원본의 바퀴 이름은 화면 전방 기준과 일치하지 않으므로 구동 모터 ID나 기존
wheel joint에 이름만으로 연결하지 않는다. 원통형 바퀴 표현은 메카넘 구동 방식의
변경을 뜻하지 않는다.

원본 해시, 부품별 BREP와 메시 해시, 그룹, 경계와 변환은
[`freecad_final.json`](../config/geometry/freecad_final.json)에 기록한다.
화면은 두 삼각형의 텍스처 면으로 제공하며 충돌 형상에서 제외한다.
MuJoCo의 STL당 삼각형 200,000개 제한에 맞춰 LiDAR 메시를 둘로 나누고,
URDF와 MuJoCo가 같은 두 조각을 읽는다. 원본 삼각형의 순서와 내용은 유지한다.
manifest에는 조각별 해시와 분할 전 STL 해시를 기록한다. 자동 관성 추정은
끄므로 색상이나 부피로 질량을 추정하지 않는다.
schema 2는 URDF와 MuJoCo가 공유하는 `meshes` 목록을 사용한다. 도구는 schema 1도
읽는다. 재생성에 성공하면 이전 manifest에 등록된 메시 중 새 모델에 쓰이지 않고
해시가 그대로인 파일을 정리한다. 사용자가 수정한 파일은 경고와 함께 보존한다.
재질의 시각 색상은 밀도나 질량 근거로 사용하지 않는다. 원본 파일에 자산별
배포 라이선스는 명시되어 있지 않으며 제공 파일의 출처를 manifest에 보존한다.

## 미확정 항목

다음 값은 manifest에서 `null`로 남긴다. 기존 실행 모델의 값을 새 CAD에
복사하거나 저장된 자세를 관절 영점으로 간주하지 않는다.

| 미확정 항목 | 필요한 근거 | 반영할 위치 |
|---|---|---|
| 관절축과 영점 | 회전축, 링크 간 기준 변환, 영점 정의와 좌우 대응 | 새 관절 URDF, MJCF, FK 검사 |
| 관절 제한과 encoder 매핑 | 실물 motor ID, 회전 부호, 영점과 안전 범위 | 관절 보정, 하드웨어와 MoveIt 설정 |
| PincOpen 구동 관계 | 구동축, 링크 길이와 구속, servo 각도별 개구 폭 | 집게 운동학과 폭→명령 변환 |
| TCP와 접촉 판정 | 손끝 기준점과 접근축, 닫힘 위치, 빈 집게·물체 접촉 시험 | TCP, 중심 보정, 접촉 판정 설정 |
| 질량과 관성 | 재질 밀도, 실측 질량, 전자부품과 배터리 배치 | URDF/MJCF inertial, 동역학 |
| 센서 측정 좌표 | 렌즈 광학축, LiDAR 스캔 기준, IMU 축과 실물 외부 보정 | 센서 TF와 새로운 보정 프로파일 |
| 움직임 충돌 모델 | 관절 확정 후 볼록 분해, 링크별 경계와 자기충돌 검사 | 충돌 메시, 구 모델, SRDF와 캐시 |
| 홈·복귀 경로 | 새 기구에서의 자세와 경로 검증 | 홈, 경유점, 수거와 복귀 설정 |

기존 `jetson_20261009` 보정은 기존 조립체의 기록이다. `freecad_final` 선택 시
해당 프로파일을 지정하면 launch가 오류를 내며, 보정이 적용된 것처럼 표시하지
않는다. 광학 프레임, TCP와 질량의 임시 기본값도 생성하지 않는다.

## 다음 구현의 완료 조건

관절·집게 구동 관계를 확보한 뒤 움직이는 링크로 분리하고 독립 FK와
URDF/MJCF를 비교한다. 이어 새 충돌 모델에서 팔 도달성, 외장과 집게 간섭,
홈·복귀 경로를 검사한다. 센서 보정과 접촉 판정은 실물 조건에서 별도로
확인한다. 이 조건이 충족되기 전까지 새 정적 형상과 기존 실행 모델의 검증을
같은 결과로 보고하지 않는다.
