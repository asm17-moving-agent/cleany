# FreeCAD 팁 체결과 회전 간섭

양손의 네 팁에서 공통 체결축과 맞물리는 강체 형상을 확인했다. 현재 CAD 조립
상태는 이 축을 중심으로 자유회전하는 힌지로 표현하지 않는다. 팁 조립체를
손끝 운반 링크의 고정 자식 링크로 분리했다. 실제 나사 체결력이나 연성 재료의
변형까지 확정한 것은 아니다.

## 원본에서 확인한 것

| 항목 | CAD 근거 |
|---|---|
| 공통 체결축 | `Distal_Rod`, `Distal_Shell`, `Removable_Tip`의 원통 구멍 축 일치 |
| 운반 링크 구멍 | 지름 2.05 mm |
| 팁과 쉘의 구멍 | 지름 3.10 mm |
| 쉘의 추가 자리 | 같은 축에 지름 5.50 mm 원통 자리, 위아래 배치 |
| 원래 자세 | 비교한 부품 사이 체적 중첩 없음 |
| 쉘과 운반 링크 | 최소 거리 약 0.20217 mm |
| 팁 전체의 공통축 회전 | ±0.1°, ±1°의 모든 검사에서 팁 내부 형상과 운반 링크의 체적 간섭 발생 |

공통 구멍 축만으로는 고정인지 회전인지 구분하지 않는다. 위 검사는 원본 BREP
강체를 공통축 주위로 회전한 뒤 `Distal_Rod`와 `Removable_Tip`의 교차 체적을
계산한다. 기존 위치에는 중첩이 없지만 양방향 회전에는 간섭이 생기는 맞물림이
있다. 따라서 원래 조립 자세를 유지하는 명목 고정 결합으로 사용한다.
검사 각도는 판단용 입력이며 회전 한계나 허용 유격의 측정값이 아니다.

쉘만 따로 돌리는 경우에는 작은 한쪽 회전에서 간섭이 없기도 하다. 이는 쉘의
여유 공간이며, 팁 전체가 자유롭게 회전한다는 근거로 사용하지 않는다. 쉘의
실제 흔들림은 나사 체결과 재질 조건을 확인해야 한다.

숫자는 원본 형상의 치수다. 지름만으로 나사 규격, 나사산, 탭 가공 여부나
필요한 체결 토크를 추정하지 않는다. 해당 나사 부품과 조립 조건은 파일에 없다.

## 모델 반영

`cad_{right|left}_gripper_tip_{L|R}` 네 링크를 추가하고, 각 링크를 기존
`cad_*_gripper_distal_*`의 고정 자식으로 연결했다. 쉘, 탈착 팁, 패드는 해당 팁
링크를 따른다. 관절축이나 회전 명령을 새로 추가하지 않았으며, 기존 34개 회전
좌표와 18개 독립 입력은 그대로다. URDF는 총 39개 링크, 34개 변화량 관절과
4개 고정 관절을 가진다. MuJoCo에서도 팁을 해당 운반 링크 아래에 고정해
별도 mocap 구동을 만들지 않는다.

원본 면 번호, 공통축, 부품별 구멍 지름, 회전 전 최소 거리와 교차 체적,
양방향 회전 검사는 [`freecad_kinematics.json`](../config/geometry/freecad_kinematics.json)의
`gripper_linkages[].tip_mounts`에 기록한다. 고정 연결은 `fixed_attachments`에서
찾을 수 있다. [`freecad_tip_mounts.json`](../config/geometry/freecad_tip_mounts.json)은
검사 각도와 수치 판정 조건을 관리한다.

## 팁에서 실물 또는 제작 사양 확인이 필요한 것

| 남은 항목 | 필요한 확인 |
|---|---|
| 나사와 조립 | 실제 규격, 길이, 나사산 또는 인서트, 위아래 조립 방식 |
| 체결 유지 | 조임 상태, 풀림 방지와 하중을 받을 때 이탈 여부 |
| 패드 고정 | 재질, 접착·끼움·일체 성형 여부와 실제 마찰 |
| 탄성과 유격 | 팁·쉘·패드의 변형, 마모와 체결 후 미세 흔들림 |
| 파지 성능 | 물체 접촉 후 변형, 유지력과 미끄러짐 |

위 항목은 null로 남긴다. CAD의 강체 간섭 검사는 재료가 휘거나 눌리는 실제
거동, 다른 축의 탄성 변형, 체결력이나 물체를 유지하는 힘을 검증하지 않는다.
이 모델을 근거로 새로운 수동 회전 관절이나 탄성 상수를 임의로 넣지 않는다.
