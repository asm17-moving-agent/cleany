# 사진과 실측으로 복원한 손목 카메라 마운트

2026-10-17 Isaac `measured-registration-v8`에서 사용한 보라색 마운트를
추출했습니다. 사진과 사용자 대략 실측을 바탕으로 만든 시뮬레이션 프록시입니다.
원본 설계 CAD, STEP, 제작 공차와 가공 홀은 포함하지 않습니다.
패키지의 Apache-2.0 라이선스 선언을 따릅니다.

| 파일 | 좌표와 단위 |
|---|---|
| `mount_legacy_jaw_m.stl` | 기존 Fixed_Jaw 원본 메시 좌표, m |
| `mount_legacy_jaw_mm.stl` | 위와 같은 형상, mm |
| `components/*.stl` | 기존 카메라 형상 body 좌표, m |

통합용 STL은 보라색 구성품 열 개의 삼각형 120개를 이어 담은 파일입니다.
Boolean 합집합이나 제작용 단일 solid 처리를 하지 않았습니다. 좌우 원본 구성품의
삼각형이 같음을 확인하고 공통 파일로 추출했습니다. 커넥터, 카메라 모듈과 나사는
개별 구성품에 포함하며, 렌즈와 케이블은 독립 MJCF의 primitive로 표현합니다.

판 가로와 세로는 42.1 × 50.7 mm, 판 위쪽 모서리에서 렌즈 중심까지는
20.5 mm, 바닥 접촉면에서 렌즈 중심까지 수직 높이는 30.9 mm입니다.
기울기, 발판 배치, 두께와 질량은 추정이며 측정 불확도는 평가하지 않았습니다.

좌표 변환, 원본 파일 hash와 추정 조건은
[형상 설정](../../config/geometry/wrist_mount_v8.json)에 기록합니다.
이 형상은 이전 `jetson_20261009` 모델에 보존합니다. 최신 CAD의 카메라 장착과
혼용하지 않으며, 적용 범위는 [모델 계약](../../docs/model.md#카메라)을 따릅니다.
전달 브랜치 `codex/wrist-camera-mount-handoff`의 `e78ac14`에서 가져왔으며,
STL과 형상 설정, 독립 MJCF는 원본 바이트를 보존합니다.
