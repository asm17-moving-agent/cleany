# cleany_dev_monitor

ROS 그래프, 카메라, 조작 단계와 호스트 리소스를 웹으로 관측한다.
기본값은 관측 전용이며, 명시적으로 켜는 운영 제어는 인증 후 기존 실물 실행기에
작업을 요청한다. 녹화와 재생 데이터는 독립 `cleany_logger`가 관리한다.

- [검증 절차](../../../docs/TESTING.md#운영-ui와-승인-흐름-검증)
- [ROS, HTTP와 승인 계약](docs/interfaces.md)
- [관측 데이터 계약](docs/data.md)

`tools/dev-monitor`의 Jetson 프로필은 `0.0.0.0:8768`에서 제공한다.
관측 화면은 인증 없이 열리며 실물 제어에는 조작키가 필요하다.
`http://<Jetson 주소>:8768/#manipulation`에서 실행 요청, 작업 제안과 실행 기록을 확인한다.
HTTP 개발 화면은 로컬 네트워크, Tailscale 또는 SSH 터널에서 사용한다.

제안은 관측 이미지와 대상을 검토한 뒤 한 번 승인한다. 승인 직전에 같은 대상을
재확인하며 다른 물체로 자동 교체하지 않는다. 실행이 끝나도 다음 작업은 다시
승인을 기다린다. `물체 1개 실행`은 기존 CLI의 자동 선택 후 즉시 실행 경로다.
소프트웨어 중단 접수와 명령 프로세스 종료는 실제 정지나 수거 성공을 의미하지 않는다.
실측 `CONFIRMED`와 시험 모드의 `ASSUMED` 결과는 구별해서 표시한다.
