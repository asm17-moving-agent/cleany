1. 전체 시간의 구성

원본 보고서의 동일한 성공 3회를 다시 분해했다. 이전 1회와 최근 2회는 물체, 경로와 시작 자세가 달라 최적화 A/B 시험으로 사용할 수 없다.

계획 = 로그에 완료 시간이 있는 IK·FK·충돌·MoveIt 계획. 궤적 준비 = 모델 확인, 경로 보간·시간 배정, 실행 전 검증을 포함한 합계. 센서 = 새 OctoMap 프레임 대기. 명령 이동 = 컨트롤러에 보낸 궤적의 명목 시간이며 모터 실측 이동 시간과 다르다. 미분리 = 나머지 연산, 서비스 대기, 동기 시작 지연, 안정화, 확인과 BT 간격. 회색 부분을 전부 제거 가능한 지연으로 해석하지 않는다.

4. 구현한 개선과 검증

구현 실행기의 execution_use_verified_local_fk를 Jetson 프로파일에서 활성화했다. 새 관절 상태, 그리퍼 설정 또는 URDF 변경으로 대조 상태가 무효화되면 MoveIt FK와 다시 비교한다. 불일치나 비정상 수치는 실패 처리한다. 명령 경로, 속도·가속도, 충돌 검사의 설정은 이번 변경으로 낮추지 않았다.
